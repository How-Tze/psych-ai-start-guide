# 六行数据查看器：需求与检查

2026-10-17，Start Guide v0.12 候选教学产物。数据复用本站 `examples/learning/within-between.csv`，与主手册六行示例一致；均为合成数据。

解压 ZIP 后双击 `data-viewer.html`，不需要安装依赖或联网。`within-between.csv` 供生成新版本时使用；网页内部已经写入同一组六行数据。

## 需求

第一轮：单文件 HTML，展示原始数据，提供全部/A/B 筛选与按人均值，中文界面，窄屏可读，标明教学数据，不用外部库、不发网络请求。

第二轮：复制当前摘要；剪贴板不可用时给出可手动复制的文本。修改前保留第一版。

## 检查

- 全部：6 行，两人；A/B 分别各 3 行。
- A 压力均值 2，睡眠困难均值 3；B 为 5、6。
- 三个筛选按钮来回切换后，行数、表格、均值和摘要同时更新。
- 复制后粘到文本编辑器核对；不可用时手动复制文本框内容。
- 窄屏与键盘可操作；断网重新打开仍可用。

本工具只展示固定教学数据和均值，不导入研究数据、不收集参与者记录、不做显著性检验。需要新功能时，把具体输入、输出和检查方式交给代码助手，再检查实际结果。

HTML 是本指南编写的示范，并非对某一商业产品完成任务的性能保证。许可沿用 Start Guide 仓库许可。
