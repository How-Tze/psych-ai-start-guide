第一次配置自己的 API：接进 Chatbox 或翻译工具

核查日期：2026-10-17。API Key 是软件调用模型服务的凭证。本页用 DeepSeek 做两条小练习：在 Chatbox 对话，或在沉浸式翻译中读一小段英文。先确认开放平台余额与费用，调用可能产生收费。

先取得服务商的凭证

从 DeepSeek 官网进入 API 开放平台，用自己的账号登录，在 Key 管理中创建本次练习专用 Key，保存到密码管理器或工具的密钥栏。检查 API 余额与用量入口。

网页聊天、客户端会员和 API 账户余额分别管理。Key 不放进研究稿件、普通聊天或截图；不再使用时可以在控制台撤销。

路线 A：Chatbox → DeepSeek

  1. 从 Chatbox 官方指南进入下载安装，打开设置。
  2. 在“模型提供方”中选 DeepSeek，将自己的 Key 填入 API Key 栏。
  3. 点击“检查”，连接成功后在模型列表选择当前可用模型。
  4. 新建对话，发一句：“请把‘个体内变化’解释给第一次做日记研究的同学，给一个例子。”
  5. 查看返回结果，再到 DeepSeek 用量页确认这次调用；开始大批量使用前先估算费用。

操作依据：Chatbox 的 DeepSeek 配置。BYOK 表示“自带 API Key”，与 Chatbox AI 托管订阅服务是两条路线。

路线 B：DeepSeek → 沉浸式翻译

从官方安装入口安装浏览器扩展。在服务设置中按DeepSeek 配置说明选择自带 Key 路线，填入凭证；模型名按当前官方模型页选择。

先翻译一小段公开英文摘要。对照原文检查术语、否定词与比较对象，再去 API 用量页查看请求。工具内订阅模型与自带 Key 的计费位置不同，先确认自己选的是哪条路线。

配置失败时按什么顺序检查

提示或现象 优先检查
Key 验证失败 是否为 DeepSeek 开放平台 Key，是否复制完整、已撤销或填错服务商
余额/额度不足 查 API 余额，不是网页聊天会员状态
模型不存在 刷新列表，与服务商当前模型名核对
连接超时 查网络与官方服务状态，避免反复启动大任务
能聊天但某种工具功能失败 分开检查客户端版本、接口格式与工具调用支持

需要程序重复处理材料时，继续两条文本起步的批处理。费用计算见API 价格表怎么读。本页依据官方配置文档编写，未发起新的付费请求；统一核查说明见版本页。
