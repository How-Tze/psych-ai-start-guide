把资料和工具接进 AI：附件、连接器、API 与 Skill

“接入”可以很简单：上传一张表，让 AI 读它；也可以是授权它查网盘、把一个模型接到翻译软件，或装一套反复使用的写作步骤。先选能解决眼前问题的方式。

四种常见接法

你想解决什么 用什么 一个例子
只读这次的材料 附件或粘贴 上传三篇论文做比较
从已有资料库取文件 连接器 / 插件 授权查找自己 Drive 中的教学文档
在一个软件中使用另一家的模型 API Key / BYOK Chatbox 连接 DeepSeek
让重复任务按熟悉步骤完成 Skill（技能） 按约定检查文献笔记、编辑中文

连接器连接数据与操作；API Key 授权模型调用；Skill 提供可复用的工作说明。安装了技能，不会自动获得访问网盘的权限。

第一条路线：先上传，完成后保存

用论文阅读教程的三篇材料，手动上传到一个对话或笔记本。完成后将比较表保存回 Zotero 或项目文件夹。材料少时，这条路线容易理解，也方便知道本次用了什么。

第二条路线：在 ChatGPT 中连接 Google Drive

官方操作核查：2026-10-17。在 ChatGPT 网页或桌面端打开 Plugins（插件），搜索 Google Drive，查看插件说明并安装。按提示登录你要使用的 Google 账号，阅读授权范围。安装后开新对话，明确让它使用 Drive。官方插件指南。

先在自己的网盘建一份只含教学内容的文档，给它一个容易辨认的标题，如“AI练习—两轮报告”。然后说：

在我的 Drive 中找到“AI练习—两轮报告”。只读取这份文档，告诉我标题、内容要点和来源链接，给出一项修改建议，先不要改原文。

打开返回的链接，确认是那份文档。接下来可以明确要求将修改稿保存为新文件。查找成功、读取成功和写回成功是三步，分别看实际结果。

不再使用时，在插件与连接设置中移除对应连接。卸载插件与断开已授权服务可能是两项操作；同时检查 Google 账号的第三方访问记录。

Gemini 与千问办公的接入

Gemini 的 Connected Apps 由账号、地区、设备和 Keep Activity 设置共同决定；在 Connectors 中选择可连接服务，再按提示授权。当前文档对关闭 Keep Activity 后的功能范围有条件说明，具体见官方连接指南。只想读一份文件时，也可直接上传或导入到笔记本。

千问办公通过扩展与连接器使用外部服务。登录钉钉只是登录身份；要让会话访问具体业务数据，还需要对应的连接授权。官方扩展说明。第一次同样选一份教学文档，先读后改。

第三条路线：Chatbox 接 DeepSeek

按第一次 API 配置取得自己的 Key，在 Chatbox 的“设置 → 模型提供方 → DeepSeek”中填写并检查连接。模型列表选当前可用项，发一段公开文本，然后去 DeepSeek 用量页确认消费。这里改变的是模型调用入口；资料仍要经过所选服务处理。

第四条路线：先把好用的步骤写下来，再考虑 Skill

完成几次论文比较后，你可能发现自己总在重复同一组要求：先确认来源、逐篇读任务与比较、标原文位置、再写下一步。这时先把要求保存为一个文本文件，下次直接使用。

产品支持 Skill 时，可以把这套稳定步骤装成技能。技能可能只含说明，也可能附脚本或工具，因此安装前读用途、来源和权限。第一次用同一份公开材料比较启用前后效果，再决定保留。本站本轮中文编辑沿用 Humanizer-zh 的表达检查原则，研究数字和判断依据仍逐项核对。

如果软件出现 MCP，它通常是在描述工具怎样连接外部服务。使用现成连接器时，先按产品授权步骤完成一项任务即可；只有需要自建连接时才继续学习协议与服务器配置。
