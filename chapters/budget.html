免费、人民币订阅与每月约 20 美元：怎样选择预算

核查日期：2026-10-17。先确定要完成的任务，再看哪个产品的功能与额度合适。下列为官方网页方案参考，币种、地区和计费周期分别注明；税费、应用商店差异与账号优惠以结算页为准。

先分清四笔不同的费用

产品是你打开的软件，模型在其中处理任务。订阅通常提供一段时间的功能与用量；API 则供软件或程序调用，常按实际用量收费。一个客户端还可能有自己的会员费。因此，付了工具会员，不一定已购买相应 API 用量。

普通文本练习先用现有免费额度。想读几篇论文、改一段结果，通常先试任务比先买高档套餐更容易判断值不值。

怎样花第一笔钱

  • 先用免费额度：完成一项文本任务，再试一次文件任务，看看实际卡在哪里。
  • 日常订阅或约 $20/月：每周反复使用，文件、较强模型或用量限制经常打断工作。优先选一个产品试一个月。
  • 约 $100/月：较低档位已持续不够用，或某项高用量任务确实值得。记录一周完成的工作与耗时，再比较升级收益。
  • 更高预算：适合需求稳定的密集任务。团队权限、机构数据规则和个人用量是不同的购买理由，先核对实际需求。

想学 vibe coding，可先用已有 Codex 或 Qwen Code 入口。Cursor 的当前方案页另列其订阅与第三方模型收费，不应按其他工具的 $20 档推定。第一次的单文件网页可以离线运行，运行它本身不消耗模型额度。

订阅是否包含 API

ChatGPT 订阅与 OpenAI API 账单分开；用 ChatGPT 登录 Codex 的方案额度也不同于 API 余额。官方定价说明。

Claude Max 5x/20x 当前分别附带每月 $100/$200 API credits，需符合资格、订阅满七天并关联 Console 组织领取，当期未用不结转；这与交互式订阅额度的使用范围不同。领取与适用范围。

GLM Coding Plan、阿里云 Token Plan 等面向指定调用环境，不能当作所有程序通用的 API 包月。具体配置见代码助手与GLM 页。

自动续费、取消与退款

月付、连续包月和“年付折合每月”分别看。年付可能一次扣除全年金额。购买时记下账号、原购买渠道和下一次扣款日。

产品 取消入口
ChatGPT 按官方取消说明在网页订阅设置或原应用商店办理
Claude 按官方说明在原渠道办理，至少提前 24 小时避免下次扣款
Google One / AI 按取消会员说明办理，降级时同时检查云存储使用量
Kimi 设置 → 订阅管理；也可按原扣费渠道管理，见取消自动续费
千问办公、WorkBuddy 从账号用量/订阅页找到原订单与续费设置；按结算所示支付渠道管理，保留关闭续费的确认

卸载应用不会取消订阅；取消续费与申请退款是两件事。办理后查看到期日期，再决定是否继续使用当前周期额度。
