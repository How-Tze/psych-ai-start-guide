第一次用工作 Agent：交给它一组文件，拿回一份报告

你可以让 AI 回答“这张表说明什么”，也可以让它打开表格、整理数字、写出报告、保存文件，再按你的意见修改。后一类能够使用工具并连续做事的助手，通常称为 Agent。

本页的目标很具体：把两轮报告练习变成可打开的文件。你负责说明用途和检查结果，Agent 负责读取、整理、保存与修改。

选一个入口

产品入口核查于 2026-10-17。先使用自己能正常访问、账号已有额度的工具。

入口 怎样开始 本练习怎样给材料
千问办公 从官方办公入口进入会话 附件上传，结果从交付物卡片下载
ChatGPT Work 网页或桌面端切换到 Work 网页上传；桌面端也可选择本地文件夹
Kimi Agent 在 Kimi 选择 Agent 模式 上传任务材料，预览并保存产物
DeepSeek Harness 安装官方预览版，按快速开始配置模型服务 选择练习目录，生成本地文件
WorkBuddy 桌面端，或微信小程序发起云端任务 上传文件；连接电脑模式另需桌面端在线

这些入口的额度与计费分别管理。DeepSeek Harness 的模型接入按其文档办理，不能把网页聊天账号直接当作 API 余额。首次练习不需要定时任务、多 Agent 或额外插件。

路线一：上传材料，直接取得文件

以千问办公为例：国内读者从 qwenwork.cn/signin用钉钉账号登录并选择个人空间；国际版登录方式见产品页。在会话添加附件，上传确认表 survey-sensitivity.csv、分析规格以及自己的第二轮稿件。账号有可用积分后即可提交任务；免费版赠送与付费套餐见预算页。

请依据附件，制作一份中文组会报告，保存为可下载文件。先用表格列出两种规则的记录数与系数，再用两段文字说明结果和需要讨论的问题。数字只取自确认表，主规则保持不变。报告后附本次使用的文件名。完成后检查每个数字，并告诉我从哪里打开文件。

在交付物卡片中打开文件。主规则应为 21、0.364、0.343；比较规则应为 15、1.081、0.720。查看表格是否挤在一起、数字是否被写进错误的行。

再发一条修改要求：

面向第一次听这个项目的同学，解释“比较规则”为什么会有另一组结果。保留数字，把解释放在表格下面，控制在两段。另存第二版，并概括修改了什么。

下载后亲自打开第二版。文件卡片中的预览、导出的文件和本地保存的文件应当对应同一版。接着把新文件名写入当前状态说明。

路线二：直接在本地目录生成报告

从 ChatGPT 官方快速开始安装适合系统的桌面端，登录后选择 ChatGPT → Work，再选择教学目录。网页 Work 可以用上传材料完成上一条路线；需要直接操作电脑文件时选择桌面端的本地工作入口。

将主手册教学包完整解压，保留 workflow 与 reference 的相对位置。让它执行：

请读取 workflow/README.md 和确认结果表。用现有 build_report.py 分别生成 my-run/round-1.md 与 my-run/round-2.md，按 README 的命令运行，不修改脚本或输入。运行后核对两份报告的行数与数字，交付文件路径和实际执行结果。如果电脑缺少 Python，请明确指出缺少什么。

这两份报告由已有脚本整理数字。需要新讨论时另起一个文件，请 Agent 提供候选解释，再由你选择采用。完整的命令和恢复练习见代码助手教程。

结果停在半路时

看到的情况 下一步
只给了正文，没有文件 指定文件名和格式，请它保存；只有聊天能力时复制到本地文本文件
说找不到结果表 在当前任务重新添加该文件，或确认所选目录
生成了脚本却没运行 问清运行环境；使用配套参考报告先继续阅读
用完额度 保存已完成产物与下一步，等额度恢复或换到已有可用入口
报告数字与原表不一致 先核对实际输入，再重做受影响的报告
