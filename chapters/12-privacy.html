上传之前：数据、隐私与未公开研究

AI 工具越来越容易读取文件、网页、代码库和本地目录，因此“能不能上传”不应等到点击上传按钮以后再想。

先把材料分成四类

材料 默认态度
已公开论文、公开网页、公开代码 通常风险较低，但仍注意版权与来源
自己的工作材料、未公开草稿 先看账户、机构和合作约定
被试数据、访谈原文、身份信息 高风险；优先脱敏、最小化或不用外部服务
API Key、密码、访问令牌 不上传、不截图公开、不写进仓库

上传前问五个问题

  1. 这是公开材料、自己的工作材料，还是包含他人数据？
  2. 是否含被试数据、访谈原文、未公开稿件、API Key 或受版权保护全文？
  3. 当前账户、机构、伦理审批或数据协议是否允许把材料交给该服务？
  4. 是否真的需要上传原文，还是可以只提供脱敏摘录、字段说明、合成示例或副本？
  5. 如果上传错误，能否删除、撤销访问并恢复？

“本地 Agent”也不等于没有隐私问题

即使 Agent 在你的电脑上工作，模型请求仍可能发送到云端 Provider；反过来，有些任务可能完全在本地模型中完成。判断数据流时，不要只看界面是不是桌面 App，要问：

文件在哪里？请求发到哪里？谁保留什么？

对科研材料的最低建议

  • 原始数据保留受保护副本；
  • 能用变量说明就不要上传完整身份信息；
  • 能用合成数据测试工作流，就先用合成数据；
  • 未公开稿件进入外部服务前，先看期刊、审稿或合作协议；
  • API Key 使用环境变量或密钥管理方式，不进入 Git；
  • Work Agent 第一次只授权一个教学/副本目录。
警告

产品隐私政策、训练选项、地区规则和机构要求都是动态事实。本页只提供决策框架；真实项目必须按当时服务条款、伦理审批和机构规定核查。

如果这些边界已经清楚，回到 30 分钟 Start Checklist 检查第一次任务是否真正形成了可继续状态。
