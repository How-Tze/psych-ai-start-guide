注册、地区与设备：第一次怎样开始

核查日期：2026-10-17。先选一个所在地能够正常使用的官方产品，做完一项练习，再考虑订阅。第一次只需要账号、浏览器和一个保存文件的目录。

在中国大陆，从这些入口开始

入口 最小操作 可以先做什么
千问 打开官网，按登录页完成验证，新建对话 学习一个方法、修改题目
DeepSeek 从官网进入网页版或官方 App，登录后开始对话 阅读六段访谈、讨论设计
Kimi 登录，新建对话并添加文件 三篇论文比较
豆包 使用已有账号进入新对话 粘贴材料，完成第一次文本任务
千问办公国内版 使用钉钉账号登录，选择个人空间 上传表格生成报告
腾讯 WorkBuddy 微信搜索官方小程序并授权登录 云端文件任务；详见产品页

账号验证方式以各登录页为准。国内千问办公的钉钉、网页与桌面入口与国际版邮箱入口不同；千问普通聊天也有独立入口。

有付费或试用提示时，先看本任务是否需要那项功能。预算页列出人民币方案与积分区别。只粘贴文本的练习，可以从账号现有可用额度开始。

ChatGPT、Claude、Gemini 怎样开通

先看地区与账号类型

ChatGPT 支持地区和 Claude 当前可用地区未列中国大陆。Google 的Gemini 网页可用地区将中国大陆标为 Workspace only，不能据此推定个人账号或 Google AI 个人订阅可用。学校/工作账号需要机构开通与许可。

Anthropic 的地区政策入口另显示一版 2026-11-12 生效的规则；本页核查日尚未到该日期。当前开户按现行帮助页检查，后续规则见官方地区政策。

ChatGPT

打开 ChatGPT，创建账号或登录，完成验证后新建 Chat 对话，粘贴六行数据做一次练习。需要完整文件时再切换 Work。桌面端安装与登录见官方快速开始，初次对话不需要 API Key。

Claude

打开 Claude，选择可持续使用的登录方式。官方要求新账号用支持地区的手机号码接收验证码，VoIP 等虚拟号码不适用；详见手机验证说明。完成后先做一段文本任务，需要更多用量时从账号套餐入口查看 Pro/Max。

Gemini

打开 Gemini，用符合条件的 Google 账号登录。个人账号与机构账号分别查看可用功能；个人付费从 Google AI 方案页进入，核对当地购买资格和结算价格。相关功能限制见官方帮助。

网页、桌面、移动端和 API 怎么选

入口 什么时候方便 第一次怎样用
网页版 对话、论文阅读、上传文件 浏览器开官网，完成一个小任务
桌面端 需要工具直接处理本地文件或长时间工作 从官网下载，选择专门的教学目录
移动端 临时记录想法、语音交流、查看结果 从官网进入应用商店安装
API 翻译插件、批量处理、自己的程序调用 按API 接入页配置服务商凭证

桌面软件访问本地文件时，仍可能调用云端模型。选好入口后查看资料与设置，再换成真实研究材料。

付款前看清什么

核对账号、币种、计费周期、是否自动续费，以及本次实际扣款额。国际网页订阅与 Apple/Google 应用内购买的结算方式可能不同；OpenAI 当前各地区支付支持见多币种账单说明。Kimi 的国内支付与权益到账问题见官方帮助。

支付失败时先核对账单信息和银行/平台提示，使用官方支持渠道。共享账号、代充或虚构地区资料都不适合作为研究环境的基础。取消与续费的具体入口集中在预算页。

第一周的安排

建立 AI练习 文件夹，第一天完成方法练习，第二天做论文比较，再选一次写作与续接。文献继续保存在 Zotero 等原有工具中。到周末看哪些步骤最常用、哪里真正遇到额度或文件限制，再决定是否订阅。
